# Rent vs Sell Profit

Веб-калькулятор для порівняння прибутковості **здачі нерухомості в оренду** та **продажу / утримання** з урахуванням зростання вартості житла.

## Навіщо

Якщо у вас є житло, важко на око оцінити, що вигідніше на горизонті кількох років: здавати його в оренду чи продати (або не здавати й покладатися лише на зростання ціни). Калькулятор підсумовує дохід від оренди, витрати на утримання, приріст вартості об’єкта та порівнює два сценарії.

## Що враховується

**Оренда:**
- сукупний дохід від місячної орендної плати за обраний термін;
- річні витрати на утримання (комунальні, податки тощо), які ви вводите;
- додатково — орієнтовне обслуговування **1% від вартості житла на рік**;
- зростання вартості об’єкта за заданим відсотком на рік.

**Продаж / утримання без оренди:**
- прибуток лише від зростання вартості житла за той самий термін і той самий темп росту цін.

Після розрахунку показується, який варіант дає більший сумарний прибуток.

## Як користуватися

1. Відкрийте `index.html` у браузері (подвійний клік або локальний веб-сервер).
2. Заповніть поля:
   - вартість житла;
   - орендна плата на місяць;
   - витрати на утримання на рік;
   - термін оренди (років);
   - темпи росту цін (% на рік).
3. Натисніть **Calculate** — у блоці результатів з’являться суми та висновок (*Renting is more profitable* / *Selling is more profitable*).

## Обмеження

Це спрощена модель для орієнтиру, а не фінансова порада. Не враховуються податки, іпотека, інфляція, простої між орендарями, комісії агентів, витрати на продаж тощо. Перед рішенням варто уточнити цифри у бухгалтера або консультанта.
